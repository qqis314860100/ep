# 文档中心模块需求

| 文档属性 | 内容 |
| --- | --- |
| 所属产品 | 仿真数模资产管理系统 |
| 模块 | 文档中心 |
| 版本 | V1.0 |
| 日期 | 2026-07-25 |
| 状态 | 产品需求基线 |

## 1. 模块目标

文档中心用于集中管理与数模资产和生产业务相关的规范、说明书、作业指导书、调试资料、验收资料和标准模板，使用户可以独立查找文档，也可以从数模资产直接找到配套文档。

文档中心不按文件后缀划分业务对象。PDF、Word、Excel 或图片只有在需要独立检索、复用、维护版本或关联多个资产时才作为知识文档管理；仅服务于单个数模资产的说明附件继续保留在资产包内。

## 2. 首期范围

- 文档分类浏览、关键词检索和结构化筛选。
- 文档详情、文件预览和下载。
- 文档草稿创建和最少信息录入。
- 当前有效版本、历史版本和版本发布。
- 文档与数模资产、标准设备模块及其他文档的关联。
- 文档收藏、评论、点赞和个人文档入口。
- 文档停用、历史保留和操作记录。

首期不包含复杂审批流、多人在线编辑、Word 内容在线编辑、电子签章、生产放行、到期自动作废和跨系统文档分发。

## 3. 用户与场景

| 角色 | 主要操作 |
| --- | --- |
| 普通用户 | 检索、查看、预览、下载、收藏和评论授权范围内的已发布文档 |
| 文档维护者 | 创建草稿、维护负责文档、上传和发布新版本、设置关联和停用负责文档 |
| 内容管理员 | 维护全部文档、规范分类、处理重复项和查看停用文档 |
| 系统管理员 | 配置角色、数据范围、文档分类和操作记录权限 |

核心场景：

1. 用户在文档中心按标题、编号、分类或关键词查找规范和作业文档。
2. 用户从数模资产详情打开关联文档，确认当前有效版本后预览或下载。
3. 文档维护者用最少字段创建草稿，上传首个版本后发布共享。
4. 文档发生变化时，维护者创建新版本并填写变更说明，发布后自动替换当前有效版本。
5. 内容管理员停用不再推荐使用的文档，但历史版本、关联和使用记录继续保留。

## 4. 业务对象与规则

### 4.1 知识文档

知识文档是用户搜索、收藏、评论和关联资产的稳定对象。文档编号、标题、分类、维护人和关联关系归属于知识文档，不因版本变化而重新创建。

### 4.2 文档版本

- 每个版本至少包含一个文件，并记录版本号、变更说明、创建人和创建时间。
- 同一知识文档内版本号唯一。
- 已发布版本不可覆盖文件、版本号和变更说明；修改内容必须创建新版本。
- 同一时间只有一个当前有效版本。
- 新版本发布后，原当前有效版本自动转为历史版本。

### 4.3 文档状态

```text
草稿 -> 已发布 -> 已停用
          |
          +-> 创建新版本草稿 -> 发布为新的当前有效版本
```

- 草稿仅维护者和有权限管理员可见。
- 已发布文档可在授权范围内检索和使用。
- 已停用文档默认不在普通检索中显示。
- 发布只表示进入平台共享范围，不代表工程审批或生产批准。

### 4.4 适用范围

- 新建或编辑文档必须显式选择“全局通用”或“指定范围”，不允许用空值表达业务含义。
- 全局通用文档不填写范围行；指定范围沿用平台族、平台子类、蓝本、基地、拉线和工序段的统一选择器。
- 既有文档迁移后标记为“范围待补充”，仍可按关键词检索，但不能被当作生产范围匹配结果。
- 一个文档可以包含多个适用范围，组合条件必须在同一个范围内匹配。

### 4.5 关联关系

- 文档可以关联多个数模资产包或标准设备模块。
- 文档可以引用其他已发布文档，但不能引用自身。
- 资产文档关联不等同于资产之间的包含、引用、配套或替代关系。
- 解除关联不删除任何文档、版本、资产、文件、评论或收藏。
- 关联两侧分别执行数据范围校验，无权对象不得显示摘要信息。

## 5. 页面与功能需求

### 5.1 文档中心首页

**DOC-HOME-01 搜索入口**

- 首页提供文档编号、标题、摘要、关键词和文件名搜索。
- 支持从常用分类、最近更新、我的收藏和我维护的文档进入。

**DOC-HOME-02 分类浏览**

- 文档分类使用管理员维护的受控字典，首期建议包含规范、说明书、作业指导书、调试资料、验收资料和标准模板。
- 分类可以新增、排序和停用；已被文档使用的分类不能物理删除。

### 5.2 文档检索

**DOC-SEARCH-01 结构化筛选**

- 支持文档分类、状态、维护人、所属部门、更新时间和文件格式筛选。
- 支持按适用范围筛选，并遵守同一适用范围匹配规则；全局通用文档在带生产条件检索时仍可见。
- 普通用户默认只检索已发布文档和当前有效版本。

**DOC-SEARCH-02 搜索结果**

- 显示标题、编号、分类、摘要、当前版本、维护人、更新时间、主要适用范围和可预览文件标识。
- 支持按相关度、更新时间、标题和编号排序。
- 历史版本不作为独立结果重复出现；详情中提供历史版本入口。
- 无结果时保留当前条件并提供清空筛选入口。

### 5.3 文档详情

**DOC-DETAIL-01 页面布局**

- 页面优先展示当前版本的文件列表和预览区，同时展示文档摘要、分类、维护人和适用范围。
- 关联数模资产和引用文档位于文档信息之后、评论之前，不因评论数量过多而被推到页面末尾。
- 历史版本使用明确入口查看，不与当前版本文件混排。

**DOC-DETAIL-02 文件预览和下载**

- PDF 支持翻页、缩放、旋转、适应宽度和全屏；图片支持缩放、旋转和全屏。
- 其他允许格式提供下载，并明确标记暂不支持在线预览。
- 预览失败不影响文档信息、关联对象和历史版本查看。
- 下载和预览均执行文档访问权限校验。

**DOC-DETAIL-03 协作**

- 用户可以收藏或取消收藏文档。
- 用户可以发表评论、上传合规图片、点赞或取消点赞。
- 评论归属于知识文档，并显示评论时查看的版本号，避免新版本发布后失去上下文。

### 5.4 文档创建与编辑

**DOC-EDIT-01 最少必填**

首次保存草稿必须填写或提供：

- 文档标题。
- 文档分类。
- 摘要。
- 维护人，默认当前用户。
- 至少一个版本文件。

关键词和关联数模资产均可后补。适用范围在新建或再次编辑时必须明确为全局通用或指定范围；发布前必须具有唯一文档编号和版本号。

**DOC-EDIT-02 自动信息**

- 系统自动记录所属部门、原始文件名、格式、大小、上传人和上传时间。
- 首个版本默认建议 V1.0，用户可以在发布前调整。
- 文件扩展名、实际类型、大小、内容摘要和安全规则沿用资产文件校验标准。

**DOC-EDIT-03 保存和并发**

- 编辑过程中可以保存草稿并继续填写。
- 存在未保存内容时离开页面必须确认。
- 两名用户同时编辑同一草稿时不得静默覆盖，后提交者应刷新后重新处理。

### 5.5 版本维护

**DOC-VERSION-01 创建新版本**

- 只有已发布文档可以创建新版本草稿。
- 新版本继承文档级标题、分类、适用范围和关联关系，维护者可以在发布前调整。
- 新版本必须提供新版本号、变更说明和至少一个文件。

**DOC-VERSION-02 发布版本**

- 发布前显示版本号、变更说明、文件清单和将被替代的当前版本，供维护者确认。
- 发布成功后新版本成为当前有效版本，搜索和详情默认使用新版本。
- 发布失败时原当前版本继续有效，新版本草稿和已上传文件继续保留。

**DOC-VERSION-03 历史版本**

- 历史版本显示版本号、变更说明、发布人、发布时间和文件清单。
- 有权限用户可以预览或下载历史版本，并明确看到“历史版本”标识。
- 历史版本不能恢复为当前版本；需要重新使用其内容时创建一个新的版本。

### 5.6 资产文档关联

**DOC-LINK-01 建立关联**

- 维护者可以按资产编号、名称或设备关键词搜索并选择关联资产。
- 保存前展示资产名称、编号、状态和主要适用范围，避免关联错误。
- 文档和资产详情保存后同步显示对应入口。

**DOC-LINK-02 访问和维护**

- 用户只能看到有权访问的关联对象。
- 关联建立、调整和解除记录操作人、时间、原值和新值。
- 数模资产停用或文档停用后关联继续保留，并显示对应状态。

### 5.7 我的文档

- 文档维护者可以按草稿、已发布和已停用查看本人负责的文档。
- 普通用户可以查看本人收藏的文档，并从列表取消收藏或进入详情。
- 支持按标题、编号、分类和更新时间筛选。

## 6. 字段规则

| 字段 | 首次保存 | 发布前 | 规则 |
| --- | --- | --- | --- |
| 文档标题 | 必填 | 必填 | 清晰描述文档主题 |
| 文档编号 | 可后补 | 必填 | 全局唯一，发布后不可直接修改 |
| 文档分类 | 必填 | 必填 | 从启用分类中选择 |
| 摘要 | 必填 | 必填 | 简要说明用途和适用对象 |
| 关键词 | 可选 | 可选 | 使用受控词条 |
| 维护人 | 必填 | 必填 | 默认当前用户，支持责任移交 |
| 适用范围 | 必填选择方式 | 必填选择方式 | 选择全局通用，或填写至少一组有依据的指定范围 |
| 关联资产 | 可选 | 可选 | 仅选择有权访问的资产 |
| 引用文档 | 可选 | 可选 | 仅选择已发布文档，不允许自引用 |
| 版本号 | 可采用默认值 | 必填 | 同一文档内唯一 |
| 变更说明 | 首版可默认首次发布 | 必填 | 新版本必须填写实际变化 |
| 版本文件 | 至少一个 | 至少一个 | 已发布版本文件不可覆盖 |

## 7. 权限与数据范围

- 普通用户只能检索和打开授权范围内的已发布文档。
- 文档维护者只能编辑本人负责的草稿和文档，内容管理员可以在授权范围内协助维护。
- 文档的任一适用范围命中用户授权范围时，用户可以访问该文档；未设置适用范围的文档按所属部门和角色授权。
- 搜索、详情、版本文件、关联对象、评论图片、预览和下载分别执行后端权限校验。
- 无权访问的文档和关联对象不得通过编号、名称、文件地址或数量信息泄露。

## 8. 验收场景

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| DOC-AC-01 | 文档检索 | 关键词和分类筛选只返回有权访问的已发布文档，每份文档只出现一次 |
| DOC-AC-02 | 最少录入 | 维护者用标题、分类、摘要、维护人和文件即可保存草稿 |
| DOC-AC-03 | 首次发布 | 补齐编号和版本号后可发布，普通用户可以检索和使用当前版本 |
| DOC-AC-04 | 新版本发布 | 新版本发布后成为当前有效版本，原版本完整保留为历史版本 |
| DOC-AC-05 | 发布失败 | 新版本发布失败时原当前版本继续可用，新版本草稿不丢失 |
| DOC-AC-06 | 资产关联 | 资产与文档详情均可进入对方，解除关联不删除任何对象 |
| DOC-AC-07 | 历史版本 | 有权限用户可以查看和下载历史版本，并始终看到历史版本标识 |
| DOC-AC-08 | 文档协作 | 收藏、评论、评论版本上下文和点赞状态保持一致 |
| DOC-AC-09 | 权限隔离 | 无权用户不能通过搜索、直链、版本文件或关联接口获得文档信息 |
| DOC-AC-10 | 文档停用 | 停用后普通检索隐藏，但版本、文件、关联和操作记录继续保留 |
