## 下一开发切片建议

文档中心应按以下顺序交付，避免一次引入全部扩展能力：

1. 文档分类、文档草稿、版本文件和首次发布。
2. 文档检索、详情、当前版本预览和下载。
3. 历史版本和新版本发布替换。
4. 资产文档双向关联。
5. 文档收藏、评论、停用和操作记录。
