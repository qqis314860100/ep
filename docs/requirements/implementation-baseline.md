| 文件预览与下载 | 已具备资产文件权限入口、PDF/图片预览界面和单文件下载链路 |

| 评论与点赞 | 已具备文字/图片评论、评论查询、作者或管理员删除、点赞和取消点赞 |
| 我的上传 | 已具备按当前用户查询上传资产和独立列表页面 |
| 字典基础维护 | 已具备字典分类/条目查询、新增、按版本修改、启停和合并接口及管理页面 |
| 治理任务编排 | 已具备任务创建、员工选择、计划新增、计划状态、完成量更新和启动后计划锁定 |

| 统一资料检索 | 已在资料检索页同时显示数模资产和知识文档两个独立结果区；任一结果区失败不影响另一结果区 |
| 资产文档互联 | 已具备资产与文档双向查询、建立、改类、解除和关系审计；关联指向逻辑文档，资产侧展示当前已发布版本 |

## 下一开发切片建议

文档中心下一切片应按以下顺序交付，避免把未完成能力混入当前闭环：

1. 新版本创建、历史版本查询和当前版本替换。
2. 文档收藏、评论和个人文档入口。
3. 文档停用、操作记录和真实数据范围授权。
