# 紧凑上传页与固定资产文件栏设计

## 目标

在不改变上传流程、字段和接口的前提下，提高上传页在 1366x768 桌面视口中的信息密度，并让右侧“资产文件”栏保持稳定尺寸。

## 布局

- 桌面端“资产文件”栏固定高度为 `430px`，继续位于元数据表单右侧。
- 文件栏采用纵向弹性布局：标题、拖拽区、校验提示、队列工具栏和自动归组按钮保持稳定高度，文件表格占用剩余空间。
- 文件数量超过可见区域时，仅文件表格内容滚动，不扩大文件栏，也不影响页面底部操作栏。
- `980px` 以下切换为单列布局，并取消文件栏固定高度，避免窄屏内容截断。

## 紧凑化

- 缩小页面标题、步骤条、区块标题、表单项和分组之间的垂直间距。
- 拖拽区由当前高度压缩至约 `88px`，保留文件类型提示和清晰的可点击区域。
- 保持现有颜色、边框、圆角和按钮层级，不引入新的视觉语言。

## 行为边界

- 上传、归组、批量角色、保存草稿和提交逻辑保持不变。
- 页面主内容继续独立滚动，底部操作栏始终可见。
- 固定高度只约束桌面端资产文件栏，不固定整个上传表单高度。

## 验证

- 运行前端 lint、typecheck 和 build。
- 在桌面视口验证文件栏高度稳定、文件队列内部滚动、底部操作栏保持可见且页面无横向溢出。
- 在小于 `980px` 的视口验证单列布局和文件栏自然高度。
