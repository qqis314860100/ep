# 需求文档导航

本目录用于按业务模块拆分详细需求。系统级产品目标、业务对象、跨模块流程、权限和总体验收标准以根目录 [产品需求文档](../../requirement.md) 为准。

## 模块划分

| 业务模块 | 需求位置 | 主要边界 |
| --- | --- | --- |
| 数模资产中心 | `requirement.md` 第 4.1-4.7、5.1、5.3-5.5、6.1-6.7、6.11-6.12 节 | 数模资产包、资产文件、检索、上传、详情、收藏、评论和资产关系 |
| 文档中心 | [文档中心模块需求](document-center.md) | 知识文档、文档版本、发布、历史版本和资产文档关联 |
| 数据治理中心 | `requirement.md` 第 5.2、6.8、7.2、8.5 节 | 盘点、标准、字典、责任、映射、清洗、确认和验收 |
| 基础数据与系统管理 | `requirement.md` 第 6.9-6.10、9 节 | 受控字典、用户角色、数据范围和操作记录 |

## 文档边界

- `requirement.md` 和模块需求只描述产品功能、数据流程、用户操作和验收规则。
- [当前实施基线](implementation-baseline.md) 单独记录当前代码已经具备、部分具备和尚未开发的能力。
- 新增或调整业务规则时，先更新系统级边界，再更新对应模块需求和验收场景。
- 实施状态变化只更新实施基线，不通过删除尚未实现的产品需求来迁就当前代码。
