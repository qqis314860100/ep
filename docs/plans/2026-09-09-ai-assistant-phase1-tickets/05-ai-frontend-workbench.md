# 05: 前端 AI 功能区（工作台 + 建议清单 + 内嵌入口）

**What to build:** 用户能在 ep 界面里完成一期两条主链路：①在 AI 问答工作台用自然语言提问，看到逐字流式回答与来源引用，可点开引用核对原文、管理自己的会话（列表/重命名/删除）；②在建议-确认清单里按状态筛选 AI 编目建议、跳转到目标资产详情核对、就地确认或驳回。同时提供轻量内嵌入口：上传成功后提示「AI 正在整理」、资产详情页展示该资产的 AI 建议与确认入口。前端只调用 ep 后端，不直连 AI 能力服务；范围外内容在界面上不可见。

**Blocked by:** 01（AI 建议-确认域闭环）、03（智能问答 SSE 会话链路）、04（入库触发 AI 编目）

**Status:** ready-for-agent

- [ ] `/ai` 问答工作台：会话侧栏 + 流式渲染（delta 追加、引用卡随 citations 出现）+ 引用跳文档/资产预览；未登录引导登录；能力服务降级时显示明确提示并可重试
- [ ] 会话管理：列表/重命名/删除/历史回看；提问后刷新不丢会话
- [ ] `/ai/suggestions` 建议-确认清单：按状态与目标筛选、分页；每项展示建议内容、依据、置信度、目标；可确认/驳回并反馈结果；范围外条目不可见
- [ ] 内嵌入口：上传成功提示「AI 正在整理…」并指向建议清单；资产详情页展示该资产 AI 建议并可确认/驳回
- [ ] 前端 api 客户端只调 ep 后端（含 SSE 消费）；不包含任何能力服务密钥/地址
- [ ] 关键交互组件测试 + 全链路浏览器验收：上传 → 建议出现 → 确认 → 资产更新留审计；提问 → 流式回答 → 打开引用

对应 spec 用户故事：1–12、13–27、28–29（前端可见部分）。
