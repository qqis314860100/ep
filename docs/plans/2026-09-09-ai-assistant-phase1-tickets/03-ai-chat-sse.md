# 03: 智能问答 SSE 会话链路

**What to build:** 用户从 AI 问答入口发出一条自然语言问题后，能收到逐字流式的回答与来源引用：ep 后端创建或续接会话，经能力服务 Port（本票用 02 的 Fake）发起流式问答，把 SSE 事件序（meta→delta→citations→done/error）透传到浏览器；整轮消息与引用在流结束后落 ep 库（会话真源）；同轮追问共享会话上下文；会话可列、可重命名、可删除、历史可读；能力服务超时或不可用时返回明确 error 事件、界面可重试且会话不丢；请求只携带用户 scope 不携带身份。

**Blocked by:** 02（AI 能力服务 Port 与 fake/HTTP 客户端）

**Status:** ready-for-agent

- [ ] 发起问答 API：新建或续接会话 → SSE 事件序 `meta → delta* → citations → done`（或中途 `error`）按序到达
- [ ] 流结束（done）后整段消息与引用落库；会话历史/列表/重命名/删除 API 可用
- [ ] 追问共享会话上下文：下一轮请求携带该会话历史（裁剪后），fake 可断言收到上下文
- [ ] 请求只携带用户 AssetScope 检索边界，不携带用户身份；鉴权沿用现有登录态（未登录 401）
- [ ] 能力服务超时/不可用 → SSE `error` 事件 + 会话保留、可重试
- [ ] 引用卡片数据（docId/位置/摘录）随 citations 事件返回，可在权限内跳转文档/资产预览
- [ ] 验收测试在主缝收口：SSE 事件序、401、scope 过滤条件入参、error 降级、会话持久化；前端可先以 Fake 联调
