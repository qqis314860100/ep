# 治理可视化设计规格（2026-09-08 定稿）

> 定稿结论：主界面用自研"治理轨道 v1"（轻量、可开发、无障碍友好）；汇报页用
> React Flow 只读全景 v2（泳道/缩放，仅该页引入依赖）。不做甘特、不做主界面自由画布。
> 视觉方向：企业专业浅色（用户选定）。原型：/tmp/ep-governance-rail-prototype.html（v1）、
> /tmp/ep-governance-reactflow.html（v2）——临时小样，不入库。

## 1. 视觉 token（企业浅色）

- 品牌绿主色 #2f7567；深 #23584d；浅底 #e7f2ef
- 信息蓝（当前步骤）#3d6fe0 / 浅底 #ecf1fc
- 逾期红 #d64545 / 浅底 #fbebea；警示琥珀 #c98a12 / 浅底 #faf2e1；完成绿 #2e9e6b / 浅底 #e5f5ec
- 中性：背景 #f5f6f8；卡片 #fff；描边 #e6e9ef；文本 #1b2230/#5b6573/#98a1ad
- 圆角 14(卡片)/9(按钮)；阴影 0 1px 2px+0 6px 18px-8px；动效 ~160ms ease

## 2. 主界面 = 治理轨道 v1（自研 PipelineRail 组件）

- 结构：状态卡×4（待整理/本周到期/已逾期/已标准化）＋ 轨道节点×6（扫描入库→问题池→整改分派→业务确认→质量验收→正式应用）
- 节点状态机：done（绿勾）/ current（蓝呼吸 pulse）/ overdue（红警示）/ wait（灰、显示待办计数）
- 节点内容：图标圆点＋名称＋计数徽标＋责任人头像（≤4，+N 折叠）
- 交互：点击节点 → 右侧/下方"该步待办"联动（AntD 列表承载）；"下一步建议"卡（一键分派/只看逾期/移交）
- 可达性：键盘 Tab+Enter 激活节点；每步说明文本非仅颜色表达状态
- 动画：Motion（framer-motion），节点状态迁移 160ms、逾期徽标呼吸

## 3. 汇报页 = React Flow 只读全景 v2（@xyflow/react）

- 引入范围：仅该页 bundle；nodesDraggable=false；fitView；浅色 Background；MiniMap
- 展示形态：节点=资产域/责任域泳道分组；边=流转；缩放看全貌；不做拖拽编辑
- 依赖：@xyflow/react（版本锁定），未来按需加自动布局
- 数据依赖 D1：泳道按真实责任人分组需登录/角色数据，先以管理员视角示意

## 4. 明确不做

- 甘特图（V2.0 决议移除；除非出现跨月多任务依赖编排的真实需求再评估 frappe-gantt/dhtmlx）
- 主界面自由画布（固定 6 步流程无增量，反而易拖乱）；暗色主题本轮不做

## 5. 落地归属

- 承载切片：N2/N3（新手路径与引导，"下一步建议"按钮）+ R1（分派工作台首屏）
- 数据前提：R2"我的待办/责任人泳道"依赖 D1 登录与角色
