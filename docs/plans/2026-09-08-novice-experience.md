# 新手体验切片 N（2026-09-08 起草）

> 目标用户：完全不懂数据治理术语的小白（上传者与新手内容管理员）。
> 判断依据：真实用户反馈——"上传后然后呢""扫什么""待整理到谁来下一步""管理员也看不懂"。
> 原则：界面带人走，而不是让人学术语。

## N1 状态解释层（低风险，先做）
- "待整理/草稿/已标准化"等状态旁加一行大白话（如 待整理 = "已入库，等待管理员整理"）。
- 我的上传 / 详情：显示"下一步是谁做什么"（员工视角：你已完成；管理员视角：等待整理）。

## N2 治理中心"新手路径"引导
- 治理中心首页按数据现状给出唯一推荐动作（Next Best Action）：
  - 有"待整理"但没扫过 → 大按钮"开始检查（自动扫描）"
  - 有扫描结果 → "查看问题清单（N 条）"
  - 问题清零 → "确认并验收"
- 术语 tooltip 化：数据标准=规矩 / 问题池=待办清单 / 正式应用=盖章定案。

## N3 单一资产"快速整理"向导
- 从"待整理"资料详情提供三步小向导：补全信息 → 确认归属 → 标记完成，不必进入整套治理页面。

## N4 首启引导（可选，需 D2 设计决策）
- 首次进入治理中心弹"你是哪种人"：交资料（带去上传页）／管理资料（带去 N2 引导）。

## 验收口径（每票）
- 一个从未打开过系统的小白，能在无人工讲解下：完成 1 次上传提交；或在 N2/N3 引导下完成 1 条资料从待整理到已标准化。
- UI 行为浏览器证据 + lint/typecheck 通过。
