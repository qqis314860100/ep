# 需求全景实施切片计划(V1.8 基线)

> **配套文档**:[需求全景拆解:功能→模块/接口/数据映射](../specs/2026-08-14-requirement-v18-mapping.md)。
> **方法**:按 coding-implementation skill 风险路由选择路径;每个切片实施前重新评分风险维度,本表为建议路径。路径含义:Fast=局部可逆;Standard=常规功能/跨文件;Strict=数据、权限、安全、生产或不可逆操作,需要设计评审、回滚计划与人工批准。
> **现状口径**:与映射表一致,implementation-baseline 已按 2026-08-14 交付事实刷新(治理闭环全链路、系统管理、责任人指派、打包下载、DOCX 转换预览均已合入 main)。

## 3. 切片明细

### L0 底座

#### SL-01 字典与产品/生产体系完整化

- **范围**:DATA-01/06、GOVERN-03 收尾、SEARCH-02 联动;模组标签受控词条(AC-32 字典面)。
- **边界**:只动字典数据与选择器联动,不触碰资产正式值;停用/合并沿用版本校验 409。
- **验收点**:平台族→子类→蓝本三层联动;八大平台原子值完整;专业类别排序;引用资产数量完整;AC-31/32/43。
- **路径**:Standard。理由:字典停用/合并不覆盖历史原值,可逆;无安全/生产边界。
- **依赖**:无。**现状**:🟡。八大平台原子值(8 项)与平台族→子类→蓝本、基地→拉线→工序段级联已齐;字典引用资产数已按资产仓储动态统计(SPECIALTY/MODULE_TAG/TAG/范围维度/ASSET_TYPE/FILE_ROLE);模组标签为受控词条(MODULE_TAG)且上传表单已字典驱动。剩余:储能(集装箱/电箱/电柜)蓝本业务编码待业务确认后补种子;全量业务字典覆盖与生产数据迁移验证随 SL-71。

#### SL-02 认证、角色与数据范围

- **范围**:AUTH-01、ADMIN-01/02;全部读/写接口的数据范围过滤;AC-10/27。
- **边界**:后端强制校验,不依赖前端隐藏;离职/失效即时失效;未登录跳转。
- **验收点**:AC-10(无权限用户搜索/直链不可见)、AC-27(关系/接口不泄露)、ADMIN-02 任一范围命中规则。
- **路径**:**Strict**。理由:认证与授权属硬 Strict 触发器(auth-or-security-boundary);需要设计评审、回滚方案与人工批准。
- **依赖**:SL-01(数据范围按蓝本/基地)。**现状**:🟡。系统管理页与后端接口(用户/角色维护、操作记录查询)已交付,演示用户与角色请求头已预留;真实认证、组织用户与数据范围过滤未接。注意:依赖公司统一认证外部接入信息,缺口见映射表 §6.1-3。

#### SL-03 操作记录统一查询

- **范围**:ADMIN-03;将既有审计事件(关系、治理、字典、文档关联、文件)统一为可查询操作记录。
- **验收点**:按用户/资料/操作类型/时间查询;记录上传、修改、下载、收藏、评论删除、点赞、停用、权限变更。
- **路径**:Standard。**依赖**:SL-02(操作人身份真实化)。**现状**:🟡。系统管理操作记录页已交付;将关系、治理、字典、文档关联、文件等既有审计事件统一为同一查询口径待收口。

#### SL-04 文件存储与访问安全生产化

- **范围**:§9 文件处理与访问;内存对象存储替换为生产对象存储适配器;下载/预览临时地址不暴露存储地址。
- **验收点**:AC-22 校验面、AC-05 下载面;`no-store`;凭据不落库不入日志。
- **路径**:**Strict**。理由:生产存储接入、环境与凭据、不可逆切换;需要人工批准与回退方案。
- **依赖**:无(可并行)。**现状**:🟡。DOCX/DOC 服务端转 PDF 在线预览已交付(LibreOffice headless,转换缺失时降级 503→前端“暂不支持在线预览”);内存/本地对象存储替换为生产适配器、预览/下载临时地址不暴露存储地址未做。

## 5. 风险与人工决策项

- **SL-02/SL-54 依赖外部认证信息**:统一认证端点、协议、组织数据源未定;在信息到位前保持演示用户与预留请求头,不阻塞其他切片。

- **SL-23 编号兼容**:若实际治理需要批量改写历史编号(超出"标记待治理"),必须升级为 Strict 并走迁移审批。
- **SL-33 拆分合并**:规则复杂且不可逆性高,建议先完成 SL-41(关系归属)再实施;涉及"系统不得依据文件名自动拆分"的强约束,实施时需专项测试。
- **验收口径**:AC-29 性能基线依赖"约定验收数据规模",需与需求侧确认规模数字后压测。
- 每个切片实施时按 coding-implementation skill 重新评分风险、记录证据并经过人工门,本计划不替代逐片路由。
