# 工程结构

读取 Agent 入口、构建文件和相关架构章节，输出当前模块边界、依赖方向、允许的跨层入口、
所有权和任务涉及的最小文件范围。不得凭通用分层模板覆盖项目事实。

检查重点：

- 新依赖是否沿允许方向流动（技术设计 §2/§3：controller -> application -> domain -> infrastructure）。
- 公开契约、数据和安全边界是否被识别（§6 API、§7 OceanBase、§9 文件访问）。
- 变更是否放在现有职责边界内（前端按业务组织，§4）。
- Sensor 是否能检测越层、漏测或构建问题。

项目落点：docs/technical-design.md、AGENTS.md、backend/ 与 frontend/ 现有分层。
